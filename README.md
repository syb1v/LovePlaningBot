# 💑 Planning Bot — Совместный планировщик для пары

Telegram-бот для пар, который помогает вместе планировать дела, отслеживать настроение, праздники и годовщины.

## ✨ Возможности

### 📋 Планирование
- **Категории** — Сериалы, Фильмы, Игры, Задачи, Цели (с иконками)
- **Элементы плана** — Добавление, редактирование, удаление с подтверждением
- **Статусы** — Ожидает → В процессе → Готово
- **Дедлайны** в формате ДД.ММ.ГГГГ с автоматическими напоминаниями
- **Заметки** к каждому элементу
- **Пагинация** списков

### 💌 Wishlist
- Предложение элементов партнёру
- Голосование «За / Против»
- Автоматическое одобрение или удаление

### 🎲 Рандомный выбор
- Случайный элемент из всех категорий или конкретной
- Выбираются только незавершённые элементы

### 💕 Настроение
- Ежедневный выбор эмодзи-настроения
- Просмотр настроения партнёра

### 📊 Статистика
- Дни вместе
- Прогресс по категориям (прогресс-бар)
- Общее количество завершённых элементов

### ⚙️ Настройки
- **Кастомные имена** — своё отображаемое имя в боте
- **Дата рождения** партнёра
- **Дата начала отношений** с автосчётчиком
- **Гибкие напоминания** — в день / за день / за 3 дня / за неделю

### 🎉 Праздники и годовщины
- Управляемые праздники (8 Марта, 14 Февраля, ДР и др.)
- Включение/выключение для каждого праздника
- Ежемесячные напоминания о месячницах
- Ежегодные уведомления о годовщинах

## 🛠 Технологии

| Компонент | Технология |
|-----------|-----------|
| Язык | Python 3.12+ |

| ORM | [SQLAlchemy 2.0](https://docs.sqlalchemy.org/) (async) |
| База данных | SQLite3 (aiosqlite) |
| Конфигурация | pydantic-settings |
| Планировщик | APScheduler |
| Линтер | Ruff |

## 🚀 Быстрый старт

### 1. Клонирование

```bash
git clone https://github.com/<username>/planning-bot.git
cd planning-bot
```

### 2. Окружение

```bash
python -m venv .venv
source .venv/bin/activate    # Linux/macOS
# .venv\Scripts\activate     # Windows
pip install -e .
```

### 3. Настройка

Создайте `.env` файл (или скопируйте из примера):

```bash
cp .env.example .env
```

Заполните:

```env
BOT_TOKEN=your_telegram_bot_token
DATABASE_URL=sqlite+aiosqlite:///data/planner.db
```

> 💡 Получить токен: [@BotFather](https://t.me/BotFather) → `/newbot`

### 4. Запуск

```bash
python run.py
```

или

```bash
python -m app
```

## 🤝 Как пользоваться

1. **Запустите бота** — `/start`
2. **Создайте пару** — бот выдаст код-приглашение
3. **Партнёр присоединяется** — вводит код через `/start`
4. **Планируйте вместе!** — используйте меню бота

## ⏰ Автоматические напоминания

Планировщик работает по **московскому времени (МСК)**:

- **09:00** — Праздники и годовщины
- **10:00** — Дедлайны элементов

Настройка когда напоминать: ⚙️ Настройки → 🔔 Напоминания
